# WireDrop Changelog - v0.10.7 (FastHost UX Hub Link & Sample Room Annotation)

**Thời gian phát hành**: 2026-11-17  
**Phạm vi**: Backend Terminal (`main.go`), Windows CLI Launcher (`fasthost.ps1`, `fasthost.bat`), Linux/macOS CLI Launcher (`fasthost.sh`).

---

## 1. Bối cảnh & Vấn đề UX
- Trước đây, khi khởi động máy chủ backend hoặc chạy FastHost Tunnel (`fasthost.bat` / `fasthost.ps1` / `fasthost.sh`), màn hình console chỉ hiển thị link có gắn cứng đuôi phòng ngẫu nhiên (ví dụ: `https://.../yzrn-s` hoặc `http://localhost:8080/yzrn-s`).
- Điều này tạo ra trải nghiệm người dùng (UX) gây nhầm lẫn:
  1. Người dùng tưởng rằng bắt buộc phải sử dụng mã phòng ngẫu nhiên được in sẵn.
  2. Người dùng không thấy link trang chủ / Web Hub (`/#`) để tra cứu cheatsheet hoặc tự nhập mã phòng mong muốn.
  3. Thiếu chú thích làm rõ mã phòng in trong terminal chỉ là **phòng mẫu / ví dụ minh họa** cho luồng truyền tải tức thì.

---

## 2. Các thay đổi chi tiết

### A. Tách biệt rõ ràng Link Web Hub (`/#`) và Ví dụ phòng mẫu
- Dòng thông tin đầu tiên hiển thị trực quan link **Web Hub (Trang chủ #)** không gắn đuôi phòng:
  - Backend: `http://localhost:PORT/#`
  - FastHost Quick: `https://<random-subdomain>.trycloudflare.com/#`
  - FastHost Custom: `https://<your-custom-domain>/#`
- Kèm chú thích hướng dẫn: `(Mở link trên để xem Cheatsheet hoặc tự tạo phòng tùy ý)`.

### B. Chú thích rõ ràng mã phòng ngẫu nhiên là Ví dụ minh họa
- Phần liên kết truyền nhanh được nhóm lại dưới tiêu đề:
  `• Ví dụ truyền nhanh (Phòng mẫu ngẫu nhiên: <slug>):`
- Liệt kê đầy đủ các cú pháp:
  - Web phát (TX)
  - Lệnh nhận (RX Linux/macOS qua `curl | sh`)
  - Lệnh nhận (RX Windows PowerShell qua `irm | iex`)
  - Lệnh tải file (RX qua `curl -sLJO`)

### C. Bổ sung cờ `-port` flag trong `main.go`
- Tích hợp package `flag` của Go Standard Library để tiếp nhận cờ `-port <port>` khi được gọi từ `fasthost` launcher (`$WiredropBin -port $Port`), ưu tiên flag -> biến môi trường `PORT` -> mặc định `8080`.

## 3. Định dạng hiển thị mới trên Console

```text
================================================================
       WIREDROP FASTHOST ONLINE (DOMAIN NGAU NHIEN)             
================================================================
 • Web Hub (Trang chu #):   https://integer-defines-...trycloudflare.com/#
   (Mo link tren de xem Cheatsheet hoac tu tao phong tuy y)

 • Vi du truyen nhanh (Phong mau ngau nhien: yzrn):
   - Web phat (TX):         https://integer-defines-...trycloudflare.com/yzrn-s
   - Lenh nhan (RX):
     Linux/macOS:           curl -sL https://integer-defines-...trycloudflare.com/yzrn-r | sh
     Windows PowerShell:    irm https://integer-defines-...trycloudflare.com/yzrn-r | iex
     Tai File:              curl -sLJO https://integer-defines-...trycloudflare.com/yzrn-r
----------------------------------------------------------------
 [Nhan Ctrl + C de dung va dong duong ham bat cu luc nao]
================================================================
```
