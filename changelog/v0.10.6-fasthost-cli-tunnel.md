# Phiên Bản v0.10.6 - Bổ Sung Công Cụ FastHost CLI (Tự Động Hóa Cloudflare Tunnel Cross-Platform)

**Ngày phát hành:** 17/11/2026  
**Trạng thái:** ✅ Đã hoàn thành, kiểm thử thành công trên cả môi trường Linux (Bash) và Windows (PowerShell/Batch)

---

## 🎯 Bối Cảnh & Mục Tiêu
Người dùng có nhu cầu host trực tiếp WireDrop từ máy tính cá nhân ra ngoài Internet để phục vụ việc chuyển giao lệnh/file mà không muốn đưa dữ liệu lên bất kỳ máy chủ đám mây nào khác. Để mang lại trải nghiệm tiện dụng tối đa, không cần cài đặt phức tạp, WireDrop bổ sung bộ công cụ **FastHost CLI** có khả năng:
1. Tự động tải `cloudflared` portable tương ứng với hệ điều hành và CPU architecture.
2. Tự động điều phối đường hầm và hiển thị đường dẫn truy cập tức thì.
3. Hỗ trợ song song 2 hệ sinh thái: Linux (Bash) và Windows (PowerShell/Batch 1-click).
4. Menu thông minh hiển thị trạng thái Custom Domain và wizard tự động cấu hình `.env`.

---

## 🛠️ Những Thay Đổi Cụ Thể

### 1. Bộ Script Điều Phối FastHost (`fasthost.sh`, `fasthost.ps1`, `fasthost.bat`)
* **Hỗ trợ đa nền tảng (Cross-Platform):**
  * `fasthost.sh`: Chạy trên Linux, macOS, Windows Git Bash, MSYS2, WSL.
  * `fasthost.ps1`: Chạy trên Windows PowerShell / PowerShell Core.
  * `fasthost.bat`: File thực thi 1-click nhấp đúp từ Windows Explorer.
* **Tự tải Cloudflare Portable:**
  * Nhận diện nền tảng (`windows-amd64`, `linux-amd64`, `linux-arm64`, `darwin-amd64/arm64`).
  * Tự tải binary portable duy nhất từ Cloudflare GitHub Releases về thư mục nội bộ `bin/` và cấp quyền thực thi.
* **Cơ chế Menu thông minh:**
  * `[1] Domain ngẫu nhiên (Mặc định)`: Mở Quick Tunnel tức thì, không cần tài khoản, không cần cấu hình. Bắt link `trycloudflare.com` và in bảng chỉ dẫn.
  * `[2] Domain cá nhân`:
    * Nếu đã cấu hình trong `.env`: Hiển thị kèm tên domain `[2] Domain cá nhân (w.yourdomain.com)`.
    * Nếu chưa cấu hình: Hiển thị `[2] Domain cá nhân (Chưa cấu hình)`. Khi chọn, CLI kích hoạt wizard hỏi Token và Custom Domain, tự động lưu vào file `.env` và kết nối ngay.
* **Dọn dẹp tài nguyên an toàn (Graceful Shutdown):**
  * Bắt sự kiện `Ctrl + C` để lập tức đóng cả máy chủ WireDrop và Cloudflared, giải phóng cổng 8080, không để lại tiến trình ngầm.

### 2. Quản Lý Cấu Hình & Bảo Mật
* Tạo tệp [.env.example](file:///e:/TT/TextConnect/.env.example) hướng dẫn cấu hình `PORT`, `CLOUDFLARE_TUNNEL_TOKEN`, `CUSTOM_DOMAIN`.
* Cập nhật [.gitignore](file:///e:/TT/TextConnect/.gitignore) loại trừ `.env`, `.env.local` và thư mục `bin/` chứa binary portable.

## 🧪 Kết Quả Kiểm Thử
* `fasthost.sh`: Kiểm thử cú pháp và luồng chạy qua Git Bash, xử lý chính xác ký tự ngắt dòng `\r`, tự nhận diện thư mục `bin/cloudflared.exe`.
* `fasthost.ps1`: Tự động tải bản portable `cloudflared.exe` (30MB) từ GitHub về `bin\`, hiển thị đúng menu trạng thái, bắt phím thoát và dừng tiến trình sạch sẽ.
