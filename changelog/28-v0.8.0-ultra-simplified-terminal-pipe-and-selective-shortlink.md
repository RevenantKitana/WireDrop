# WireDrop v0.8.0 - Terminal-Native Pipe & Rút Gọn Link Tuyển Chọn
**Ngày phát hành:** 2026-11-19

### Added
- `term_pipe.go`: Hỗ trợ Terminal-Native Pipe trực tiếp với cú pháp siêu ngắn:
  - `wiredrop <room>`: Mở phiên REPL tương tác bên phát (TX).
  - `wiredrop <room> -r`: Mở luồng nhận dữ liệu (RX).
  - `cat file | wiredrop <room>`: Pipe dữ liệu trực tiếp sang phòng.
  - `wiredrop <room> -r | bash`: Pipe dữ liệu sang bash thực thi trực tiếp.
- Cơ chế rút gọn link tuyển chọn (Opt-In Shortlink): Cờ `-s` trên CLI (`wiredrop <room> -s`) và nút `[⚡ RÚT GỌN]` trên Web RX.
- Endpoint `POST /api/shorten` kết nối Gateway `s.wd.io.vn` theo nhu cầu.

### Changed
- FastHost Console phân tách rõ chế độ Quick Tunnel trực tiếp (mặc định) và Quick Tunnel + Rút gọn `s.wd.io.vn`.
- Nâng phiên bản `const Version = "v0.8.0"` trong `main.go`.
