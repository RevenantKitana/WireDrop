# WireDrop v0.7.2 - Cổng Shortlink s.wd.io.vn & Tích Hợp FastHost
**Ngày phát hành:** 2026-11-19

### Added
- Thư mục `gateway/worker.js`: Mã nguồn Cloudflare Worker Gateway cho `s.wd.io.vn` với whitelist bảo vệ tên miền đích (`*.trycloudflare.com`, `*.wd.io.vn`).
- Tích hợp tự động đăng ký shortlink trong `host.go` khi FastHost khởi chạy.
- Console in trực tiếp shortlink `https://s.wd.io.vn/<slug>-s` và `https://s.wd.io.vn/<slug>-r`.

### Changed
- Nâng phiên bản `const Version = "v0.7.2"` trong `main.go`.
