# Phiên Bản v0.10.0 - Giao Diện Retro Tối Giản (Retro Minimalist Terminal UI)

* **Ngày thực hiện:** 2026-11-17
* **Mục tiêu:** Chuyển đổi toàn diện phong cách giao diện Web Client sang trường phái **Retro Tối Giản (Terminal / Hacker Aesthetic)**: triệt tiêu toàn bộ bo góc (sharp brutalist geometry, 0px border-radius), đồng bộ font Monospace trên toàn bộ ứng dụng, sử dụng bảng màu Phosphor Green (`#00ff66`) tương phản cao trên nền đen sâu, chuyển đổi icon/emoji màu mè thành các ký hiệu terminal và bracket tag sắc nét (`[TX]`, `[RX]`, `[ SCRIPT ]`, `[ FILE ]`, `[ 409 : LINE BUSY ]`).

---

## 1. Chi Tiết Thay Đổi (Changes)

### `Changed` (Giao Diện & Trải Nghiệm Người Dùng)
* **`public/style.css`**:
  * **Triệt tiêu toàn bộ bo góc:** Thiết lập quy tắc toàn cục `border-radius: 0 !important;`, tạo cảm giác terminal máy trạm cổ điển dứt khoát.
  * **Monospace toàn bộ:** Đồng bộ kiểu chữ trên toàn bộ giao diện (`JetBrains Mono`, `Fira Code`, `Cascadia Code`, `Consolas`, `Courier New`, `monospace`).
  * **Bảng màu Phosphor CRT Green:**
    * Nền đen sâu: `--bg-base: #060806`, panel `--bg-panel: #0c120c`, input/terminal `--bg-box: #030503`.
    * Màu nhấn xanh lân quang (Phosphor Green): `--phosphor-green: #00ff66` kết hợp hiệu ứng phát sáng nhẹ `text-shadow: 0 0 8px rgba(0, 255, 102, 0.35)`.
    * Màu cảnh báo Amber (`#ffb000`) và Red (`#ff3344`).
  * **Kiểu dáng nút bấm (Terminal Buttons):** Thiết kế dạng nút hộp terminal không bo góc, hiệu ứng hover viền sáng và active đảo màu (chữ đen nền xanh phosphor).
  * **Thanh cuộn Retro:** Thiết kế thanh cuộn vuông vức, tối giản viền đen/xanh.

* **`public/index.html`**:
  * **Logo:** Chuyển `⚡ WireDrop` sang `>_ WIREDROP` mang hơi thở dòng lệnh.
  * **Header & Khóa vật lý:** Tinh gọn các biểu tượng, nút hủy chuyển thành `[✕]`.
  * **Trang chủ (`/#`):**
    * Khung banner ASCII / Monospace tinh gọn: `// INSTANT WEB → TERMINAL RELAY`.
    * Form chọn phòng chuyển sang style prompt: `>> KẾT NỐI ĐẦU DÂY (SLUG)` cùng nút bấm `[ TX : MỞ PHÁT ]` và `[ RX : MỞ NHẬN ]`.
    * 3 thẻ hướng dẫn tối giản với các tag `[ 01 : TX ]`, `[ 02 : RX ]`, `[ 03 : LOCK ]`.
  * **Bên phát (TX):**
    * Thanh chọn slot: `[ SCRIPT / TEXT ]` và `[ FILE ĐƠN ]`.
    * Khu vực kéo thả file: Khung nét đứt retro cùng biểu tượng ASCII `[ + ]`.
    * Bảng lệnh đích: Nút tab `LINUX`, `WINDOWS`, `WEB` cùng nút `[ COPY ]`.
  * **Bên nhận (RX):**
    * Màn hình terminal đọc dữ liệu: Nhãn `>> DỮ LIỆU NHẬN (RX_STREAM):` và văn bản xanh CRT trên nền đen sâu.
  * **Modal 409 Line Busy:** Phong cách hộp thoại cảnh báo hệ thống với tag `[ 409 : LINE BUSY ]` và viền đỏ sắc nét.

* **`public/app.js`**:
  * Chuẩn hóa toàn bộ thông báo trạng thái đồng bộ với phong cách bracket terminal:
    * `[ ĐÃ COPY ✓ ]`
    * `[ĐANG LƯU...]`, `[ĐÃ LƯU ✓]`, `[BỊ KHÓA !]`, `[LỖI LƯU !]`
    * `[NẠP FILE...]`, `[ĐÃ NẠP ✓]`, `[ RX ĐÃ KẾT NỐI ✓ ]`, `[ DỮ LIỆU ĐÃ TỰ HỦY ✓ ]`
    * Text chờ RX: `# [RX_STREAM: ĐANG CHỜ DỮ LIỆU TỪ TX...]`

## 2. Kiểm Thử & Xác Nhận (Verification)

1. **Biên dịch Binary:**
   ```bash
   go build -ldflags="-s -w" -o wiredrop.exe .
   ```
   *Kết quả:* Biên dịch thành công, nhúng toàn bộ HTML/CSS/JS mới vào binary kích thước ~7MB.

2. **Kiểm tra giao diện:**
   * Mở `/#`: Trang chủ hiển thị chuẩn retro monospace, sắc nét, không viền bo.
   * Mở `/1-s` (TX): Thanh chọn slot, trình soạn thảo terminal và vùng kéo thả file hiển thị chuẩn bảng màu CRT Phosphor Green.
   * Mở `/1-r` (RX): Terminal nhận dữ liệu chữ xanh phát sáng huyền bí trên nền đen sâu.
   * Thao tác Copy / Lưu / Upload: Toast và Sync Indicator hiển thị dạng `[ ĐÃ LƯU ✓ ]`, `[ ĐÃ COPY ✓ ]`.
