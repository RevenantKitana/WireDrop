# WireDrop v0.8.2 - Tối Ưu Hóa Máy Ảo, Delivered ACK & Hỗ Trợ Alpine Linux (wget)
**Ngày phát hành:** 2026-11-19

### Added
- Lệnh `wiredrop install` và `wiredrop uninstall` (kèm `install.bat`) cài đặt nhị phân vào User PATH `%LOCALAPPDATA%\Microsoft\WindowsApps` (Zero-Admin Elevation).
- Tín hiệu Delivered ACK: Server phát sự kiện SSE `payload_consumed` khi CLI đọc xong dữ liệu; Web RX gửi beacon qua `POST /{room}/ack`.
- Huy hiệu giao nhận trên Web TX (`✓ ĐÃ ĐẾN MÁY ĐÍCH`) và thông báo nhận tin tức thì trong Terminal REPL.
- Ngăn xếp 3 gói text gần nhất dưới textarea Web TX (100% `localStorage`, 0 byte server).
- Hỗ trợ cú pháp Alpine Linux / BusyBox (`wget -qO- <url> | sh`) trên Web RX, Trang chủ và Terminal REPL.

### Changed
- Nâng phiên bản `const Version = "v0.8.2"` trong `main.go`.
