# Phiên Bản v0.13.0 - Khắc Phục Mất Cân Đối Giữa Tab File & Text (Proportional Card Density)

* **Ngày thực hiện:** 2026-11-17
* **Mục tiêu:** 
  1. **Khắc phục lỗi mất cân đối giữa tab File và Text:** Xử lý triệt để hiện tượng diện tích thẻ tab File không tương xứng với tác dụng (trước đây thẻ File bị lọt thỏm, để lại 200px khoảng trắng vô nghĩa ở nửa dưới, trong khi tab Text lấp đầy 100%).
  2. **Tối ưu hóa diện mạo tab File:** Cho phép vùng kéo thả (`.dropzone-box`) và thẻ thông tin file đã nạp (`.file-loaded-card`) tự động chiếm trọn 100% chiều cao cột trái một cách bề thế, cân xứng hoàn hảo với cột hiển thị lệnh bên phải.
  3. **Loại bỏ vết co giãn `resize`:** Đặt `resize: none;` cho Textarea, ngăn icon co giãn `///` đè lên đường phân cách trục giữa.
  4. **Cân xứng hóa Cột Phải (Lệnh RX):** Thẻ `.rx-cmd-card` tự động dãn cách hợp lý theo chiều dọc, căn thẳng hàng nút `[COPY]` ở đáy cột phải ngang bằng với nút thao tác bên cột trái.
  5. **Đồng bộ Trang Chủ (`/#`):** Chuyển toàn bộ trang chủ về cấu trúc hộp đôi 2 cột song song chuẩn mực.

## 1. Chi Tiết Thay Đổi (Changes)

### `Changed`
* **`public/style.css`**:
  * Tinh chỉnh `.dropzone-pane`, `.dropzone-box` và `.file-loaded-card` với thuộc tính `flex: 1; height: 100%`.
  * Bổ sung phân nhóm bố cục thẻ file: Tiêu đề đỉnh `[ FILE ĐANG SẴN SÀNG ]`, phần thân trung tâm (Tên file, Dung lượng, Cơ chế lưu RAM) và chân thẻ chứa nút `[✕ HỦY & ĐỔI FILE]`.
  * Cấu hình `.rx-cmd-card` với `flex: 1; justify-content: center;` nhằm tạo trọng tâm cân đối cho cột phải.
  * Đặt `resize: none;` cho `#senderTextarea`, loại bỏ hoàn toàn vết co giãn góc của trình duyệt.
* **`public/index.html`**:
  * Chuyển cấu trúc Trang Chủ (`#homeView`) sang khối đôi 2 cột `.dual-box` (Cột trái: Brand + Nhập Slug; Cột phải: Hướng dẫn 3 bước).
  * Chuẩn hóa cấu trúc HTML thẻ nạp file trong `#fileDropzone`.
* **`public/app.js`**:
  * Hỗ trợ cập nhật chú thích động `#cheatNote` khi chuyển đổi qua lại giữa Văn bản và File.
  * Hỗ trợ deep-link trực tiếp vào tab file thông qua `#file` hoặc `?mode=file`.
