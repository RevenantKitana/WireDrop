# WireDrop v0.6.0 - 16MB Chunked Dual-Buffering Backpressure Pipe (Zero-Disk Streaming)
**Ngày phát hành:** 2026-11-17

### Added
- Động cơ truyền file lớn Zero-Disk qua khối chuẩn 16MB và bộ đệm kép `make(chan *ChunkItem, 2)`, điều tiết áp lực ngược (Backpressure) tối đa 32MB RAM server, vượt qua giới hạn 100MB Cloudflare Edge.
- Cơ chế tạm dừng chờ RX ở Chunk 0 (`waiting_rx`), tự động kích hoạt tiếp khi RX kết nối.
- Endpoint `POST /{room}-s/abort` cho phép hủy phiên truyền tải và giải phóng RAM tức thì.
- Web RX hỗ trợ Native File System Access API (`showSaveFilePicker`) ghi thẳng xuống đĩa cứng (0 byte RAM trình duyệt), tương thích đồng thời với `curl -sLJO`.

### Changed
- Nâng phiên bản `const Version = "v0.6.0"` trong `main.go`.
