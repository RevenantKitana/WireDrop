# WireDrop v0.7.0 - Động Cơ Tăng Tốc Turbo HTTP Core
**Ngày phát hành:** 2026-11-18

### Added
- Vi khung Sub-Chunk Streaming 256KB với `sync.Pool`: Xả dữ liệu tức thì xuống socket RX ngay khi TX nạp được 256KB đầu tiên (TTFB ~20ms).
- Pipelining song luồng (`MAX_CONCURRENCY = 2`) với van áp suất trượt (Sliding Window Backpressure), khóa cứng RAM server ở mức $2 \times \text{ChunkSize}$.
- Phân tầng kích thước chunk thích ứng theo dung lượng file (8MB, 16MB, 32MB).
- Cơ chế chống trùng lặp khi retry giữa chừng (`sess.FlushedTotalBytes`).
- Nâng cấp giao thức Cloudflare Tunnel sang `--protocol http2` trong `host.go`.

### Changed
- Nâng phiên bản `const Version = "v0.7.0"` trong `main.go`.
