# Phiên Bản v0.10.5 - Bổ Sung Hướng Dẫn TX CLI Trực Quan Trên Web Client

**Ngày phát hành:** 17/11/2026  
**Trạng thái:** ✅ Đã hoàn thành, kiểm thử giao diện thực tế và đẩy lên Git

---

## 🎯 Bối Cảnh & Mục Tiêu
Người dùng thường xuyên có nhu cầu truyền script, file hoặc đẩy dữ liệu từ Terminal/CLI của máy phát trực tiếp vào đầu dây phát (`/:room-s`) mà không cần mở trình duyệt để paste nội dung hay kéo thả file. Để biến WireDrop thành một bảng tra cứu lệnh (cheatsheet) toàn diện cả 2 chiều, giao diện Web Client cần cung cấp hướng dẫn và mẫu lệnh **TX CLI** rõ ràng, tiện sao chép với slug phòng được bind tự động.

---

## 🛠️ Những Thay Đổi Cụ Thể

### 1. Trang Chủ (`/#`): Cheatsheet 3 Cột Cân Đối Với Lệnh TX CLI
* Bổ sung khối lệnh Terminal thực thi trực tiếp vào Cột 1 `[1. BÊN PHÁT (TX)]`:
  * **Đẩy script/văn bản vào dây:**  
    `curl -s -X POST --data-binary @script.sh host/:room-s`
  * **Hoặc đẩy qua pipe dòng lệnh:**  
    `echo "cmd" | curl -s -X POST --data-binary @- host/:room-s`
* Tối ưu hiển thị `.rx-cmd`: Chuyển từ `white-space: nowrap; overflow-x: auto;` sang `white-space: pre-wrap; line-height: 1.4;` giúp dòng lệnh tự động xuống dòng gọn gàng, loại bỏ hoàn toàn các thanh cuộn ngang gây thô ráp trên nền retro monochrome.
* Đồng bộ 3 cột: Cột 1 (TX CLI), Cột 2 (RX Execute Script), Cột 3 (RX Download File) đều sở hữu khối lệnh monospace chuẩn mực.

### 2. Trang Bên Phát (`/*-s`): Bổ Sung Tab [TX CLI] Tại Thanh Lệnh Đáy
* Thêm tab `[TX CLI]` song song với `[LINUX]`, `[WIN]`, `[URL]` trên thanh lệnh cố định phía dưới.
* Logic tương tác động (`public/app.js`):
  * Khi chọn `[TX CLI]`: Tiêu đề tự động đổi thành `LỆNH ĐẨY DỮ LIỆU TỪ TERMINAL (TX):`.
  * **Chế độ Văn bản:** Hiển thị lệnh `curl -s -X POST --data-binary @script.sh host/:room-s`.
  * **Chế độ File:** Tự động phát hiện tên file (hoặc placeholder `file.ext`) và hiển thị `curl -s -F "file=@<tên_file>" host/:room-s`.
  * Hỗ trợ nút `[COPY]` để sao chép lệnh TX CLI chỉ với 1 cú click.
  * Hỗ trợ URL param `?tab=tx` để deep-link trực tiếp vào giao diện hướng dẫn TX CLI.

### 3. Khung Kéo Thả File (Dropzone)
* Cập nhật dòng gợi ý trong khung dropzone:  
  `Kéo thả file hoặc nạp từ CLI: curl -s -F "file=@name" host/:room-s`

### 4. Cache-Busting
* Cập nhật version query string cho asset tĩnh lên `?v=0.10.5` trong `public/index.html` để đảm bảo trình duyệt người dùng luôn tải phiên bản CSS/JS mới nhất.
