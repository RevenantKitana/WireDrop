# WireDrop v0.6.2 - Sửa Lỗi Trắng Trang Chủ (/#), Stream UI Guards & Hỗ Trợ Tên File UTF-8
**Ngày phát hành:** 2026-11-18

### Fixed
- Sửa lỗi cú pháp JS trong `public/app.js` gây trắng trang chủ `/#`.
- Bảo toàn tên file tiếng Việt có dấu và khoảng trắng: Giải mã `X-File-Name` qua `url.PathUnescape` và xuất header `Content-Disposition` theo chuẩn RFC 5987 (`filename*="UTF-8''..."`).

### Added
- Khóa bảo vệ giao diện TX (`isUploadingTx`) và RX (`isDownloadingRx`) ngăn chặn polling và SSE ghi đè trạng thái khi đang truyền tải file.

### Changed
- Nâng phiên bản `const Version = "v0.6.2"` trong `main.go`.
