# Changelog 24: v0.6.2 - Khắc Phục Lỗi Trắng Trang Chủ (/#), Bảo Vệ Giao Diện Stream TX/RX & Hỗ Trợ Tên File Tiếng Việt UTF-8

## 1. Bối cảnh & Vấn đề (Context & Pain Points)
1. **Lỗi trang chủ `/#` (và các view SPA) hiển thị trống trơn:**
   - Khi mở `http://localhost:8080/#` (hoặc `/`), trang chỉ hiện phần Header và Footer, vùng nội dung chính hoàn toàn trống.
   - **Nguyên nhân gốc rễ:** Trong quá trình gộp mã ở [public/app.js](file:///E:/TT/WireDrop/public/app.js) tại bản `v0.6.1`, một đoạn 40 dòng cuối của hàm `uploadChunkedFile` bị nhân đôi (dòng 582–621) tạo ra dấu đóng ngoặc dư `};`, dẫn tới lỗi `Uncaught SyntaxError: Unexpected token ';'`. Toàn bộ file `app.js` dừng biên dịch ngay lập tức, hàm điều phối `detectRole()` không chạy nên `#homeView` vẫn giữ `display: none`.
2. **Xung đột cập nhật trạng thái khi đang Stream Đa Mảnh (Polling/SSE vs Active Dashboard):**
   - **Bên Gửi (TX):** Khi nạp Mảnh 0 của file nhiều mảnh, server phát sự kiện `payload_updated` cho cả phòng. Nếu TX nhận lại sự kiện này (hoặc qua polling 3s) và gọi `showActiveFile()`, bảng tiến trình nạp `fileUploadProgressCard` sẽ bị ẩn sớm dù các mảnh tiếp theo vẫn đang tải.
   - **Bên Nhận (RX):** Chu kỳ polling 3s gọi `renderPayload()` đè lại trạng thái `recvFileReadyCard`, làm ẩn bảng đồng hồ tải về `recvFileProgressCard` khi tải file lớn mất hơn 3 giây.
3. **Tên file có dấu cách / Tiếng Việt (UTF-8) trong Chunked Upload:**
   - Client mã hóa tên file qua `encodeURIComponent` trên header `X-File-Name` để hợp lệ chuẩn HTTP ASCII, nhưng server chưa giải mã (`url.PathUnescape`), khiến tên file hiển thị dạng `%20` / `%C3%A1`.

## 2. Giải pháp Thực hiện (Implementation Details)

### 2.1 Khắc Phục Triệt Để Lỗi Cú Pháp JS & Chống Cache Cũ
- Loại bỏ hoàn toàn khối mã bị lặp trong [public/app.js](file:///E:/TT/WireDrop/public/app.js), khôi phục toàn vẹn luồng khởi chạy `detectRole()` cho `/#`, `/*-s` và `/*-r`.
- Cập nhật tham số cache-busting trên [public/index.html](file:///E:/TT/WireDrop/public/index.html) lên `?v=0.6.2` cho cả `/style.css` và `/app.js`.
- Bổ sung định tuyến an toàn cho `/index.html` trong `roomDispatcher` ([main.go](file:///E:/TT/WireDrop/main.go)).

### 2.2 Khóa Bảo Vệ Giao Diện Khi Đang Truyền Tải (TX/RX Stream UI Guards)
- **Khóa bảo vệ TX (`isUploadingTx()`):** Chặn các sự kiện `payload_updated` và chu kỳ polling 3s ghi đè lên `fileUploadProgressCard` khi phiên cắt mảnh đang hoạt động.
- **Theo dõi tiến độ RX kéo file trên TX (`chunk_ack` & `payload_cleared`):** Khi RX kéo từng mảnh (kể cả bằng `curl`), thẻ trạng thái TX cập nhật trực tiếp `RX đang kéo mảnh k/N...` và tự động giải phóng về khung kéo thả kèm thông báo `[RX ĐÃ NHẬN XONG FILE ✓]` ngay khi hoàn tất.
- **Khóa bảo vệ RX (`isDownloadingRx`):** Ngăn chu kỳ polling 3s và sự kiện `payload_cleared` làm tắt bảng `recvFileProgressCard` trong suốt quá trình ghi stream xuống đĩa cứng.

### 2.3 Giải Mã Tên File UTF-8 & Chuẩn Hóa RFC 5987 `Content-Disposition`
- Tại `handleChunkUpload` ([handler_pipe.go](file:///E:/TT/WireDrop/handler_pipe.go)), giải mã `X-File-Name` bằng `url.PathUnescape` để giữ nguyên tên file tiếng Việt và khoảng trắng.
- Bổ sung hàm `formatContentDisposition()` xuất đồng thời `filename="..."` và `filename*=UTF-8''...` chuẩn RFC 5987.
