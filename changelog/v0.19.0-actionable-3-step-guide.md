# Phiên Bản v0.19.0 - Tái Cấu Trúc Bảng Hướng Dẫn Sử Dụng Thực Dụng (Actionable 3-Column Cheatsheet)

* **Ngày thực hiện:** 2026-11-17
* **Mục tiêu:** Tái thiết kế toàn diện bảng hướng dẫn ở trang chủ từ dạng "vừa thừa vừa thiếu" sang dạng bảng tra cứu lệnh thực chiến (Cheatsheet):
  1. **Loại bỏ phần THỪA:**
     - Xóa bỏ mục quảng cáo tính năng ngầm `[3. AN TOÀN] Đúng 1 kết nối mỗi đầu. Đọc xong xóa trắng khỏi RAM` (không phải bước thao tác của người dùng).
     - Xóa bỏ đường dẫn giả định `domain/1-r` cứng nhắc.
  2. **Bổ sung phần THIẾU:**
     - **Cột 1 [1. BÊN PHÁT (TX)]:** Quy trình rõ ràng: Nhập slug, bấm `TX (PHÁT)` mở Web, dán script shell hoặc kéo thả file.
     - **Cột 2 [2. THỰC THI LỆNH (RX)]:** Đầy đủ câu lệnh cho cả 2 môi trường chính: Linux/macOS (`curl -sL ... | sh`) và Windows PowerShell (`irm ... | iex`).
     - **Cột 3 [3. NHẬN FILE (RX)]:** Đầy đủ cho cả Terminal (`curl -sLJO ...` tự lưu tên file gốc) và Trình duyệt Web (bấm `RX (NHẬN)` để tải file).
  3. **Tương tác động (Dynamic Binding):**
     - Các khối code terminal tự động cập nhật URL và mã phòng ngẫu nhiên thời gian thực theo ô nhập slug ở trên.
