# WireDrop v0.7.1 - Tải File Nền Cho Thiết Bị Di Động & Screen Wake Lock
**Ngày phát hành:** 2026-11-18

### Added
- Chế độ Native OS Download cho thiết bị di động (`isMobileDevice()`) hoặc trình duyệt không hỗ trợ File System Access API: Cho phép tắt màn hình hoặc chuyển app khi tải.
- Đồng bộ tiến độ tải ngầm qua sự kiện SSE `chunk_ack`.
- Tích hợp Screen Wake Lock API (`acquireWakeLock()`) giữ màn hình sáng khi theo dõi tiến trình.

### Changed
- Giao diện nút tải trên Mobile đổi thành `TẢI VỀ MÁY (CHẠY NGẦM)`.
- Nâng phiên bản `const Version = "v0.7.1"` trong `main.go`.
