# WireDrop v0.3.3 - Trang Chủ Điều Phối (/#) & Tối Giản Giao Diện Bên Nhận
**Ngày phát hành:** 2026-11-16

### Added
- Trang chủ điều phối `/#` với Room Launcher Card và bảng hướng dẫn nhanh 3 bước.
- Điều hướng thông minh trong `main.go`: Browser vào `/` mở trang chủ; CLI vào `/` tự chuyển hướng sang `/1-r`.
- Bộ lọc `detectRoleAndSlug()` trong `public/app.js` tự ngắt kết nối SSE khi ở trang chủ.

### Removed
- Xóa bỏ ghi chú rườm rà `.reverse-note` trên giao diện bên nhận (`*-r`).

### Fixed
- Sửa lỗi build Render Docker bằng cách chuẩn hóa `go.mod` về `go 1.22`.
