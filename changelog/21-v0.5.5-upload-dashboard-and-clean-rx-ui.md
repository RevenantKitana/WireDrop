# WireDrop v0.5.5 - Upload Dashboard Đo Tiến Trình & Tinh Giản Giao Diện Web Nhận (RX)
**Ngày phát hành:** 2026-11-17

### Added
- Bảng đồng hồ tiến trình nạp file (`fileUploadProgressCard`) hiển thị phần trăm, dung lượng, tốc độ thời gian thực (MB/s), thời gian dự kiến (ETA) và nút hủy tải lên (`xhr.abort`).

### Removed
- Xóa bỏ nhãn văn bản thừa `BÊN NHẬN (RX): [KẾT NỐI: HOẠT ĐỘNG]` trên thanh thao tác đáy của Web RX.
