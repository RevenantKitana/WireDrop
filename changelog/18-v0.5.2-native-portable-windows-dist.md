# WireDrop Changelog - v0.5.2 (Native Go Portable Windows All-in-One & Dist Separation)

**Thời gian phát hành**: 2026-11-17  
**Phạm vi**: Go Backend (`host.go`, `main.go`), Công cụ Build (`build-portable.bat`), Thư mục phân phối (`dist/`).

---

## 1. Mục Tiêu & Bối Cảnh (Objective)
- Chuyển hóa toàn bộ logic của `fasthost` (tự tải Cloudflare Portable, thanh tiến độ console, menu điều phối tunnel, dọn dẹp tiến trình an toàn) vào thẳng **mã nguồn Go chuẩn (Zero-Dependency)**.
- Phân biệt rạch ròi 100% giữa:
  1. **File build ở root (`wiredrop.exe`):** Dành cho phát triển (dev), thử nghiệm và chạy máy chủ backend chuẩn (mặc định lắng nghe `:8080`).
  2. **File build Portable trong `dist/` (`dist/wiredrop-portable.exe`):** Bản phát hành độc lập dành cho người dùng cuối trên Windows. Nhấp đúp chuột là tự động kích hoạt giao diện FastHost Tunnel mà không cần bất kỳ file `.bat` hay `.ps1` nào đi kèm.

---

## 2. Chi Tiết Thay Đổi (Changes)

### Added
* `host.go`: Hiện thực hóa toàn bộ logic FastHost bằng 100% Go Standard Library:
  - Hàm `findOrDownloadCloudflared()`: Định vị trong `bin/`, `%LOCALAPPDATA%`, hoặc tự động tải `cloudflared-windows-amd64.exe` trực tiếp từ GitHub Releases.
  - Thanh tiến độ console Monospace: `[████████░░░░] 60% (18.2 / 30.1 MB)...`.
  - Tích hợp server nội bộ chạy trong Goroutine (không cần spawn tiến trình Go thứ 2, triệt tiêu lỗi chiếm dụng port).
  - Quản lý vòng đời tiến trình: Bắt `os.Interrupt` / `SIGTERM` để kill `cloudflared` và shutdown server êm xuôi.
  - Hỗ trợ dừng màn hình khi bấm đúp từ Windows Explorer (`pauseOnExit`).
* `build-portable.bat`: Script 1-click tự động biên dịch nhị phân độc lập ra `dist/wiredrop-portable.exe`.
* `dist/README.txt`: Hướng dẫn sử dụng nhanh dành cho người dùng tải gói phân phối.

### Changed
* `main.go`:
  - Nâng version lên `v0.5.2`.
  - Tách hàm `createHandler()` và `runServer()` để tái sử dụng trong cả 2 chế độ.
  - Cơ chế nhận diện thông minh:
    - Nếu tên file thực thi chứa chữ `portable` (ví dụ `wiredrop-portable.exe`) hoặc có subcommand `host`: Chạy thẳng vào Menu FastHost Portable.
    - Nếu chạy từ root (`wiredrop.exe`) hoặc có cờ `server`: Chạy máy chủ backend tiêu chuẩn.

## 3. Hướng Dẫn Kiểm Thử (Verification)

1. **Kiểm tra bản build root (Server Mode):**
   ```powershell
   go build -ldflags="-s -w" -o wiredrop.exe .
   .\wiredrop.exe -port 8080
   # Kết quả: Mở server backend trực tiếp như thông thường.
   ```

2. **Kiểm tra bản build portable (Portable Mode):**
   ```powershell
   .\build-portable.bat
   .\dist\wiredrop-portable.exe
   # Kết quả: Tự động mở Menu tương tác FastHost Cloudflare Tunnel mà không cần đối số.
   ```
