# WireDrop v0.5.2 - Native Go FastHost Windows & Phân Tách Thư Mục dist/
**Ngày phát hành:** 2026-11-17

### Added
- `host.go`: Hiện thực hóa toàn bộ logic FastHost bằng 100% Go Standard Library, tự động kiểm tra và tải `cloudflared` nếu chưa có.
- Subcommand `wiredrop host` chạy trực tiếp Cloudflare Tunnel không cần phụ thuộc script bên ngoài.
- Thư mục phát hành độc lập `dist/` đóng gói `wiredrop-portable.exe` và tài liệu hướng dẫn.
