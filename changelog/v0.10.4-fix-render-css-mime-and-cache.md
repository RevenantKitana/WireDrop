# Phiên Bản v0.10.4 - Sửa Triệt Để Lỗi CSS Không Áp Dụng Khi Deploy Lên Render (MIME & Cache Fix)

* **Ngày thực hiện:** 2026-11-17
* **Mục tiêu:** Khắc phục triệt để hiện tượng CSS không hoạt động hoặc không được áp dụng khi triển khai dự án lên nền tảng Render:
  1. **Xử lý xung đột bộ nhớ đệm (Browser & Cloudflare CDN Edge Cache):**
     - *Hiện tượng:* Render đặt sau lớp Reverse Proxy/CDN Cloudflare. Trước đây, `index.html` gọi `/style.css` không có chuỗi truy vấn phiên bản (`?v=...`) và máy chủ Go dùng `http.FileServerFS` không gửi kèm header `Cache-Control`. Trình duyệt và Cloudflare lưu cache tệp CSS cũ từ các lần deploy trước.
     - *Hệ quả:* Khi tải HTML mới chứa các class mới (`.payload-frame`, `.rx-fixed-bar`, `.form-pane`), trình duyệt lại áp dụng tệp CSS cũ trong cache (vốn chỉ chứa các class cũ như `.dual-box`). Do đó, giao diện hiển thị vỡ nát hoặc trông như trang HTML trần không có CSS.
  2. **Bảo đảm chuẩn MIME Type trên Linux/Docker (`Content-Type: text/css`):**
     - Trên môi trường container Linux siêu tối giản (`scratch` / `alpine`), cơ sở dữ liệu `/etc/mime.types` không tồn tại. Nếu hàm dò MIME của hệ thống bị lọt, trình duyệt kích hoạt cơ chế bảo vệ nghiêm ngặt (Strict MIME Checking trên kết nối HTTPS) và từ chối áp dụng tệp CSS nếu bị gán nhãn `text/plain`.
  3. **Đồng bộ hóa Font chữ JetBrains Mono toàn cầu:**
     - Tích hợp liên kết Google Fonts `JetBrains Mono` vào `<head>`, giúp mọi thiết bị (kể cả không cài sẵn font) đều hiển thị font monospace retro sắc nét.

---

## 1. Chi Tiết Thay Đổi (Changes)

### `Fixed`
* **`main.go`**:
  * Thay thế `http.FileServerFS` tự động bằng các hàm phục vụ chuyên biệt:
    * `serveStyleCSS`: Ép cứng `Content-Type: text/css; charset=utf-8` và `Cache-Control: no-cache, no-store, must-revalidate`.
    * `serveAppJS`: Ép cứng `Content-Type: application/javascript; charset=utf-8` và `Cache-Control: no-cache, no-store, must-revalidate`.
    * `serveIndexHTML`: Bổ sung header `Cache-Control: no-cache, no-store, must-revalidate`.
  * Cập nhật cả ở ServeMux chính và hàm điều phối `roomDispatcher`.
* **`public/index.html`**:
  * Thêm tham số chống cache: `<link rel="stylesheet" href="/style.css?v=0.10.4">` và `<script src="/app.js?v=0.10.4"></script>`.
  * Bổ sung Google Fonts cho font chữ `JetBrains Mono`.

## 2. Kiểm Thử & Xác Nhận (Verification)
* Kiểm tra header trả về qua curl:
  ```text
  Content-Type: text/css; charset=utf-8
  Cache-Control: no-cache, no-store, must-revalidate
  Pragma: no-cache
  Expires: 0
  ```
* Yêu cầu file tĩnh với tham số `?v=0.10.4` được đáp ứng mã `200 OK` tức thì.
* Biên dịch lại binary `wiredrop.exe` thành công.
