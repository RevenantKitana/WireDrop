# Phiên Bản v0.10.3 - Tinh Giản Diễn Giải, Slug 4 Ký Tự Ngẫu Nhiên & Cheatsheet 3 Cột Thực Chiến

* **Ngày thực hiện:** 2026-11-17
* **Mục tiêu:** Tinh giản ngôn ngữ giao diện, ngăn ngừa đụng độ phòng và xây dựng bảng tra cứu lệnh thực chiến:
  1. **Loại bỏ toàn bộ diễn giải dài dòng:**
     - **Trang nhận (RX):** Bỏ ghi chú `// Dữ liệu sẽ tự hủy khỏi RAM sau khi đọc hoặc tải về (Burn-After-Read)`. Nút `[COPY DỮ LIỆU]` được tích hợp trực tiếp lên góc phải hàng tiêu đề `BÊN NHẬN (RX): [KẾT NỐI: HOẠT ĐỘNG]`.
     - **Trang chủ (Home):** Bỏ slogan phụ `Khóa vật lý 1-1 độc quyền • Tự hủy sau khi nhận (Burn-After-Read)`.
     - **Trang gửi (TX):** Bỏ dòng ghi chú phụ `Nhận và thực thi ngay lập tức qua pipe` dưới thanh lệnh RX.
  2. **Đầu dây mặc định 4 ký tự chữ số ngẫu nhiên (`[a-z0-9]`):**
     - Thay thế slug cố định `"1"` bằng mã ngẫu nhiên 4 ký tự (hơn 1.6 triệu tổ hợp), triệt tiêu nguy cơ đụng độ phòng khóa 1-1 (`409 Conflict`) ngay từ lượt truy cập đầu tiên.
     - Tự động điền mã ngẫu nhiên vào ô nhập liệu và các liên kết gợi ý ở trang chủ; đồng bộ cả ở CLI redirect và log terminal Go.
  3. **Tái cấu trúc Bảng hướng dẫn 3 cột thực chiến (Actionable Cheatsheet):**
     - Xóa bỏ mục lý thuyết ngầm `[3. AN TOÀN]`.
     - Cột 1 `[1. BÊN PHÁT (TX)]`: Quy trình khởi tạo bàn phát và nạp nội dung.
     - Cột 2 `[2. THỰC THI LỆNH (RX)]`: Khối lệnh Linux/macOS (`curl -sL ... | sh`) và Windows PowerShell (`irm ... | iex`).
     - Cột 3 `[3. NHẬN FILE (RX)]`: Khối lệnh Terminal lưu file gốc (`curl -sLJO ...`) và nút Web `RX (NHẬN)`.
     - Toàn bộ khối lệnh terminal tự động chèn đúng URL và mã phòng ngẫu nhiên theo thời gian thực (Live Binding).
