# Changelog 31: v0.8.3 - Hỗ Trợ Luồng Nghịch (Guest TX → Host RX) & Shortlink Uplink Cho Máy Khách

## 1. Bối Cảnh & Vấn Đề Kiến Trúc (Reverse Flow Architectural Blind Spot)
Trong mô hình thực chiến hàng ngày của WireDrop:
* Khi người dùng chạy lệnh `wiredrop <room> -r` trên máy tính Host (nơi đang chạy WireDrop Server hoặc FastHost), máy Host đóng vai trò là **Bên Nhận (RX)** để đón dữ liệu (log, file backup, artifact build) đẩy về từ Máy Khách (Guest VM, Alpine Linux, container, remote server, hoặc điện thoại).
* Ở kịch bản này, Máy Khách chính là **Bên Phát (TX)**.
* **Điểm mù kiến trúc cũ:**
  1. Khi chạy `wiredrop <room> -r`, màn hình console chỉ in thông báo thụ động: `Đang chờ dữ liệu từ Đầu Phát (TX)...` mà hoàn toàn **không có bất kỳ câu lệnh cheatsheet nào** để người dùng copy sang máy khách nhằm đẩy dữ liệu về.
  2. Cờ `-s` (Shortlink) tuy được parser nhận diện nhưng bị bỏ quên trong hàm `runTerminalReceiver`, không đăng ký link ngắn `s.wd.io.vn/<room>-s`.
  3. Giao diện Web RX (`/room-r`) chỉ có nút `[COPY DỮ LIỆU]`, hoàn toàn thiếu nút để sao chép hoặc rút gọn đường dẫn mời gửi TX (`/room-s`) cho đối tác hoặc thiết bị khác.
  4. Cơ chế kết nối Live Stream (`GET /<room>-r?live=1`): Trước đây nếu Host RX mở kết nối trước khi phòng tồn tại, server trả về `# WireDrop: (empty)` rồi ngắt kết nối thay vì giữ luồng chờ TX kết nối.

WireDrop `v0.8.3` giải quyết triệt để toàn bộ các điểm mù trên theo kim chỉ nam:
> **"A giao dịch với B để ít quy trình nhất — Chân lý tối giản để vừa đạt."**

## 2. Chi Tiết Thay Đổi (Detailed Changes)

### 2.1 Cheatsheet Uplink Trong Terminal Receiver ([term_pipe.go](file:///E:/TT/WireDrop/term_pipe.go))
* **Tự động sinh Cheatsheet Uplink:** Khi chạy `wiredrop <room> -r`, console hiển thị bảng hướng dẫn đẩy dữ liệu tức thì cho mọi môi trường máy khách:
  * `📱 Web / Điện thoại (TX):     https://s.wd.io.vn/<room>-s` (hoặc `http://<LAN_IP>:<Port>/<room>-s`)
  * `🐧 Linux/macOS curl đẩy file: curl -s -F "file=@<path>" <TX_URL>`
  * `📟 Linux/macOS curl đẩy text: echo "data" | curl -s -X POST --data-binary @- <TX_URL>`
  * `🏔️ Alpine Linux (wget file):  wget -qO- --post-file=<path> <TX_URL>`
  * `(Nếu máy khách ĐÃ CÓ WireDrop binary: cat <file> | wiredrop <room>)`
* **Hỗ trợ cờ rút gọn `-s` trong RX:** Chạy `wiredrop <room> -r -s` sẽ tự động đăng ký với Shortlink Gateway `s.wd.io.vn` và in link `https://s.wd.io.vn/<room>-s` siêu ngắn trong cheatsheet.
* **Bảo toàn chế độ im lặng (Silent Mode):** Khi pipe (`wiredrop 88 -r | bash` hoặc có cờ `-q`), Cheatsheet được triệt tiêu tự động để giữ nguyên vẹn dòng dữ liệu thô.

### 2.2 Nút Sao Chép & Rút Gọn Link Mời Gửi TX Trên Web RX ([public/index.html](file:///E:/TT/WireDrop/public/index.html) & [public/app.js](file:///E:/TT/WireDrop/public/app.js))
* **Giao diện Web RX (`/room-r`):**
  * Tại thanh thao tác cố định phía dưới (`.rx-fixed-bar`), bổ sung 2 nút điều khiển:
    * `[⚡ COPY LINK MỜI GỬI (TX)]` (`btnCopyTxInvite`): Sao chép ngay đường link đầu phát TX (`<origin>/<slug>-s` hoặc `s.wd.io.vn/<slug>-s` nếu đã rút gọn) vào Clipboard, hiển thị toast `[✓ ĐÃ SAO CHÉP LINK MỜI GỬI (TX)]`.
    * `[⚡ RÚT GỌN]` (`btnShortenRx`): Gọi `/api/shorten`, nhận `short_s`, tự động sao chép vào Clipboard và cập nhật trạng thái `✓ ĐÃ RÚT GỌN`.
* **CSS Responsive Mobile ([public/style.css](file:///E:/TT/WireDrop/public/style.css)):** Cập nhật `.rx-bar-header` tự động co dãn `flex-wrap: wrap; gap: 8px;` trên màn hình nhỏ.

### 2.3 Khởi Tạo Phòng Chờ Tức Thì Cho Live Pipe ([handler_pipe.go](file:///E:/TT/WireDrop/handler_pipe.go))
* Khi Máy Nhận (Host RX) kết nối với cờ `?live=1` (như trong lệnh `wiredrop <room> -r`): Nếu phòng chưa từng tồn tại, server tự động khởi tạo phòng (`globalRooms.GetOrCreate(slug)`) và duy trì luồng stream mở sẵn, sẵn sàng hứng dữ liệu ngay khi Guest TX đẩy lên mà không bị ngắt kết nối vòng lặp.

### 2.4 Đồng Bộ Phiên Bản & Đóng Gói Nhị Phân
* Nâng phiên bản `const Version = "v0.8.3"` trong [main.go](file:///E:/TT/WireDrop/main.go).
* Cập nhật cache-busting query: `app.js?v=0.8.3`, `style.css?v=0.8.3`.
* Biên dịch bản phát hành:
  * `wiredrop.exe`
  * `dist/wiredrop-portable.exe`
* Cập nhật bản cài đặt toàn cục `%LOCALAPPDATA%\Microsoft\WindowsApps\wiredrop.exe` qua lệnh `wiredrop install`.
