# WireDrop v0.4.5 - Bổ Sung Hướng Dẫn TX CLI Trực Quan Trên Web Client
**Ngày phát hành:** 2026-11-17

### Added
- Trang chủ `/#` bổ sung lệnh đẩy dữ liệu bằng cURL: `curl -s -X POST --data-binary @script.sh host/:room-s`.
- Khung kéo thả file bổ sung gợi ý nạp file từ dòng lệnh: `curl -s -F "file=@name" host/:room-s`.
