**Ngày:** 2026-11-16  
**Tác giả:** TextConnect Architecture Team  
**Trạng thái:** Hoàn tất giai đoạn thiết kế (Spec & Rules Initialized)

## 1. Mục Tiêu (Objective)
* Định hình trọn vẹn bản đặc tả hệ thống cho dự án **TextConnect (TermPipe)**.
* Chốt giải pháp công nghệ: **Go (Golang 1.22+)** với kiến trúc **100% Standard Library (Zero-Dependency)**.
* Thiết lập bộ quy tắc bắt buộc về quản lý changelog và tổ chức code trong [CLAUDE.md](../CLAUDE.md) và [rule/claude.md](../rule/claude.md).

---

## 2. Chi Tiết Thay Đổi (Changes)

### Added
* `SPECIFICATION.md`: Bản đặc tả kiến trúc v2.1.0 bao quát toàn bộ:
  * Hai chế độ cốt lõi: Script Box (Batch Mode) & Live Terminal Pipe (Interactive Stream).
  * Hỗ trợ đa nền tảng: Linux/macOS (`curl | sh`) & Windows PowerShell (`irm | iex`).
  * Tính năng truyền file & Zero-RAM Pass-Through Pipe cho file lớn.
  * Phòng vệ 7 cạm bẫy hệ thống: chuẩn hóa CRLF `\r\n`, nhịp tim keep-alive 20s, payload limiter.
  * Mô hình bảo mật 4 lớp: Khóa ghép đôi 1-to-1 IP, Burn-after-read, mã PIN 4 số, TLS 1.3.
  * Đóng gói Single Binary với `//go:embed`.
* `CLAUDE.md` & `rule/claude.md`: Định nghĩa bộ quy tắc phát triển:
  * Quy tắc bắt buộc tạo changelog cho mỗi đợt viết code/tính năng.
  * Quy tắc phân tách file changelog trong thư mục `changelog/`.
  * Quy chuẩn code idiomatic Go, module hóa và an toàn concurrency (`sync.RWMutex`).
* `changelog/README.md`: Bảng mục lục theo dõi toàn bộ các phiên bản changelog.
