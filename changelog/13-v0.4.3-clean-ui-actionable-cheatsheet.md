# WireDrop v0.4.3 - Tinh Giản Diễn Giải, Slug 4 Ký Tự Ngẫu Nhiên & Cheatsheet 3 Cột Thực Chiến
**Ngày phát hành:** 2026-11-17

### Added
- Hàm `randomSlug(4)` trong `main.go` và `generateSlug(4)` trong `public/app.js` sinh slug ngẫu nhiên `[a-z0-9]`, triệt tiêu đụng độ phòng khóa 1-1.
- Bảng hướng dẫn thực chiến 3 cột tại trang chủ với live binding URL động cho Linux (`curl`), Windows (`irm`) và tải file (`curl -sLJO`).

### Removed
- Xóa bỏ toàn bộ slogan và ghi chú lý thuyết dài dòng trên Trang Chủ, TX và RX.
