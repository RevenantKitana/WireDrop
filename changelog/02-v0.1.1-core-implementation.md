# WireDrop v0.1.1 - Hoàn Thiện Mã Nguồn Go Cốt Lõi
**Ngày phát hành:** 2026-11-16

### Added
- `go.mod`: Khởi tạo Go module với 100% Go Standard Library (Zero-Dependency).
- `room.go`: Quản lý bộ nhớ RAM thread-safe qua `sync.RWMutex` và worker dọn dẹp phòng nền.
- `handler_text.go`: Giao thức chuyển tiếp văn bản/script, chuẩn hóa CRLF `\r\n` -> `\n`, endpoint SSE `GET /{room}/events`.
- `handler_stream.go`: Luồng Live Terminal Pipe không đệm qua `http.Flusher`, nhịp tim `: keep-alive\n` mỗi 20s.
- `handler_file.go`: Truyền file 2 chiều với phân tầng bộ đệm (RAM $\le$ 15MB, đĩa tạm > 15MB).
- `public/`: Giao diện Web SPA Developer Dark Mode nhúng trực tiếp vào binary qua `//go:embed`.
- `main.go`: Khởi động HTTP Server, router `http.ServeMux`, logging middleware và CORS.
