# Changelog: v0.1.1 - Hoàn Thiện Toàn Diện Mã Nguồn Go (Core Implementation)
**Ngày:** 2026-11-16  
**Tác giả:** TextConnect Architecture Team  
**Trạng thái:** Biên dịch thành công 100% (Build & Verified)

---

## 1. Mục Tiêu (Objective)
* Hiện thực hóa toàn bộ kiến trúc **TextConnect (TermPipe)** bằng **Go (Golang 1.22+)** theo đúng [01-core-two-ended-wire-and-physical-lock.md](../spec/01-core-two-ended-wire-and-physical-lock.md).
* Đóng gói toàn bộ Frontend Web SPA (HTML/CSS/JS) vào bên trong duy nhất 1 file binary `.exe` độc lập (~9.8MB) bằng `//go:embed`.
* Hỗ trợ đầy đủ 3 chế độ: Script Box (Batch), Live Terminal Pipe (Interactive Stream), và File Transfer (Zero-RAM Stream).
* Kiểm thử chức năng toàn diện trên môi trường thực tế.

## 2. Chi Tiết Thay Đổi (Changes)

### Added
* `go.mod`: Khởi tạo module Go với kiến trúc **100% Standard Library (Zero-Dependency)**.
* `room.go`: Quản lý struct `RoomState` và `RoomManager`:
  * Quản lý bộ nhớ RAM thread-safe bằng `sync.RWMutex`.
  * Khóa ghép đôi độc quyền (1-to-1 IP Pairing Lock).
  * Mã PIN 4 số chống brute-force (tự hủy phòng nếu sai 3 lần).
  * Cờ tự hủy nội dung sau 1 lần đọc (`BurnAfterRead`).
  * Worker dọn dẹp bộ nhớ RAM ngầm tự động (quét mỗi 5 phút, giải phóng phòng sau 2 giờ không hoạt động).
* `handler_text.go`: Xử lý giao thức chuyển tiếp văn bản / script:
  * Phân biệt thông minh giữa Trình duyệt (Web SPA) và Dòng lệnh (`curl`, `wget`, `PowerShell`).
  * Chuẩn hóa tự động ký tự xuống dòng CRLF `\r\n` $\rightarrow$ `\n` bảo vệ bash Linux.
  * Endpoint `GET /{room}/out` và `POST /{room}/out` nhận/trả log kết quả từ máy ảo.
  * Endpoint Server-Sent Events (SSE) `GET /{room}/events` đồng bộ tức thì lên Web UI.
  * Endpoint khởi tạo nhanh: `/i` (Linux bash alias `r`) và `/i.ps1` (Windows PowerShell function `r`).
* `handler_stream.go`: Xử lý Live Terminal Pipe:
  * Endpoint `GET /{room}-r`: Sử dụng `http.Flusher` stream chunked không đệm trực tiếp vào `bash`.
  * Nhịp tim tự động `: keep-alive\n` mỗi 20 giây chống ngắt kết nối ngầm từ Proxy/Cloud.
  * Endpoint `POST /{room}-s`: Bơm lệnh từ Máy A sang kênh Go Channel của Máy B.
* `handler_file.go`: Xử lý truyền file 2 chiều:
  * Tải file: `GET /{room}/{file}`.
  * Upload file từ terminal: `PUT /{room}/{file}` (`curl -T`).
  * Cơ chế đệm thông minh: File $\le$ 15MB lưu RAM, file > 15MB stream xuống đĩa tạm `/tmp`.
  * Zero-RAM Pass-Through Pipe (`/{room}/pipe`) cho file cực lớn nhiều GB qua `io.Pipe()`.
* `public/index.html`, `public/style.css`, `public/app.js`:
  * Giao diện Developer Dark Mode cao cấp (màu nền `#0d1117`, viền `#30363d`, điểm nhấn `#00ffc4`).
  * 3 Tab chuyển đổi mượt mà: Script Box, Live Terminal, Files.
  * Cheat-sheet chuyển đổi nhanh lệnh chạy cho Linux (`curl`), Windows (`irm | iex`), và phím tắt (`r`).
  * Kéo & Thả file (Drag-and-Drop) và tự sinh lệnh tải `curl -LO`.
  * Tự động lưu ngầm (Debounced Auto-save 300ms).
* `main.go`:
  * Định tuyến router ServeMux của Go 1.22+.
  * Nhúng toàn bộ thư mục `public/` bằng `//go:embed`.
  * Middleware logging và CORS.

## 3. Kết Quả Kiểm Thử (Verification Results)
* **Biên dịch:** `go build -v .` $\rightarrow$ Mã thoát `0`. Tạo ra file thực thi duy nhất `textconnect.exe` (9.79 MB).
* **Kiểm tra API Health:** `GET /health` $\rightarrow$ Trả về `OK`.
* **Kiểm tra Script Lưu & Đọc:** `POST /demo` $\rightarrow$ `OK (v2)`, `GET /demo` $\rightarrow$ `echo 'Hello from Host Machine'`.
* **Kiểm tra Log Output:** `POST /demo/out` $\rightarrow$ `OK`, `GET /demo/out` $\rightarrow$ Trả về đúng log.
* **Kiểm tra Web SPA Delivery:** Gửi header `Accept: text/html` $\rightarrow$ Trả về `text/html; charset=utf-8` kèm đầy đủ mã nguồn nhúng của `app.js` và `style.css`.
* **Kiểm tra File Upload/Download:** `PUT /demo/test.txt` $\rightarrow$ `UPLOADED`, `GET /demo/test.txt` $\rightarrow$ Tải về nguyên vẹn 33 bytes.
