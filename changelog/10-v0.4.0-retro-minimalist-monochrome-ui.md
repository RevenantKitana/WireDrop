# WireDrop v0.4.0 - Đại Tu Giao Diện Retro Monochrome & Tối Giản Cực Hạn Mã Nguồn
**Ngày phát hành:** 2026-11-17

### Changed
- `public/style.css`: Chuyển sang phong cách Retro Monochrome đơn sắc (nền trắng `#ffffff`, chữ đen `#000000`, viền `1px solid #000`, triệt tiêu bo góc `border-radius: 0`).
- `public/index.html`: Cập nhật logo `WIREDROP` cổ điển, tối giản cấu trúc DOM.
- `public/app.js`: Tái cấu trúc logic client bằng helper `$()`, tinh gọn toàn bộ event handlers.

### Removed
- Cắt giảm 1.435 dòng mã nguồn thừa, loại bỏ Dark Mode và các hiệu ứng màu mè phức tạp.
