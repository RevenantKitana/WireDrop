# Phiên Bản v0.4.0 - Đại Tu Giao Diện Retro Monochrome & Tối Giản Cực Hạn Mã Nguồn

* **Ngày thực hiện:** 2026-11-17
* **Mục tiêu:** Đại tu toàn diện phong cách giao diện Web Client sang trường phái **Retro Đơn Sắc (Monochrome Paper & Brutalist Minimalist)** và cắt giảm triệt để hơn 1.400 dòng code thừa:
  1. **Phong cách Giấy Trắng Mực Đen (Monochrome Paper Theme):** Triệt tiêu toàn bộ màu mè, gradient, bóng đổ và chế độ tối. Sử dụng nền trắng tinh khiết `#ffffff`, chữ đen `#000000`, đường viền `1px solid #000`, nút đảo màu đen/trắng và font chữ Monospace chuẩn dòng lệnh.
  2. **Triệt tiêu toàn bộ bo góc (Sharp Geometry):** Toàn bộ các thành phần nút bấm, khung nhập liệu, tab và modal áp dụng `border-radius: 0 !important;` dứt khoát.
  3. **Cắt giảm cực hạn mã nguồn (Extreme Code Reduction):** Tinh giản 1.435 dòng code dư thừa trên cả 3 file client (`style.css`, `index.html`, `app.js`), giúp client đạt độ phản hồi tức thì và dung lượng siêu nhẹ (< 5ms load time).

## 1. Chi Tiết Thay Đổi (Changes)

### `Changed`
* **`public/style.css` (863 dòng $\rightarrow$ Tinh gọn):**
  * Đồng bộ toàn diện font Monospace (`JetBrains Mono`, `Fira Code`, `Consolas`, `monospace`).
  * Loại bỏ hoàn toàn Dark Mode và các hiệu ứng phát sáng phức tạp để quay về thẩm mỹ retro tối giản thuần túy.
  * Nút bấm hộp terminal: Nút chính `.btn-black` (nền đen chữ trắng), nút phụ `.btn-white` (nền trắng chữ đen).
* **`public/index.html`:**
  * Logo đổi thành `WIREDROP` gạch chân cổ điển với hộp định danh `TX /slug-s`.
  * Trạng thái dây trực quan: `TX ●──RX ○` (chưa kết nối RX) hoặc `TX ●──RX ●` (đã kết nối RX).
  * Loại bỏ các cấu trúc `div` lồng nhau không cần thiết, tối ưu hóa ngữ nghĩa DOM.
* **`public/app.js`:**
  * Tái cấu trúc bằng helper `$ = id => document.getElementById(id)`.
  * Tinh gọn toàn bộ hệ thống xử lý sự kiện: Auto-Save debounce 300ms, thụt lề phím Tab 4 khoảng trắng, Drag & Drop upload file đơn nguyên tử và quản lý kết nối EventSource SSE.
