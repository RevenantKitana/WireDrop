# Changelog: v0.4.0 - Hiện Thực Hóa Trọn Vẹn "Sợi Dây 2 Đầu Thuần 1 Chiều"
**Ngày:** 2026-11-16  
**Tác giả:** TextConnect Engineering Team  
**Trạng thái:** Hoàn tất hiện thực & Kiểm thử (Completed Implementation)

---

## 1. Mục Tiêu (Objective)
* Chuyển hóa toàn bộ đặc tả kiến trúc **v3.0.0** thành mã nguồn Go thuần (100% Standard Library).
* Hiện thực hóa cơ chế:
  * Khóa 1-1 vật lý "Cầm 2 đầu dây" theo IP (`SenderIP` và `ReceiverIP`).
  * Đơn vị dữ liệu nguyên tử (`PipeSlot` - 1 Script hoặc 1 File tại một thời điểm).
  * Xử lý chống crash Windows PowerShell `irm | iex` khi slot rỗng.
  * Phân tách giao diện Web triệt để: Giao diện Bên Phát (`*-s`) có soạn thảo, Giao diện Bên Nhận (`*-r`) thuần chỉ đọc (không có ô soạn thảo).
* Đóng gói toàn bộ backend, frontend và routing vào một file thực thi duy nhất (`textconnect.exe`) kích thước ~6.75 MB.

## 2. Chi Tiết Thay Đổi (Changes)

### Backend (Go 1.22+)
* `room.go`:
  * Định nghĩa `PayloadType` (`PayloadEmpty`, `PayloadText`, `PayloadFile`).
  * Cấu trúc `PipeSlot` quản lý dữ liệu nguyên tử, hỗ trợ bộ đệm RAM/Disk và `io.Pipe()` cho file siêu lớn.
  * Cấu trúc `RoomState` tích hợp khóa 2 đầu (`SenderIP`, `ReceiverIP`), quản lý kênh SSE `StatusEvent` và cơ chế `BurnAfterRead`.
  * Các phương thức thread-safe: `SetScript`, `SetFile`, `InitStreamPipe`, `Consume`, `ClearSlot`, `CanAccess`.
  * Bộ dọn dẹp phòng nền (`startCleaner`) tự động hủy phòng sau 24h không hoạt động.

* `handler_pipe.go`:
  * Xử lý thống nhất luồng `-s` (Sender/Master) và `-r` (Receiver/Worker).
  * Chuẩn hóa ký tự xuống dòng (`\r\n` -> `\n`) cho mọi script tải về.
  * Bảo vệ Windows PowerShell: Trả về `# TextConnect: (empty)\n` khi slot trống, tránh lỗi `EmptyStringNotAllowed`.
  * Kiểm soát kết nối 1-1: Từ chối máy thứ ba với HTTP `409 Conflict: Line busy`.
  * Hỗ trợ streaming dữ liệu thời gian thực qua `http.Flusher`.
  * Cung cấp Server-Sent Events (SSE) tại `/api/status/{room}` cập nhật trạng thái kết nối và slot theo thời gian thực.

* `main.go`:
  * Cấu hình Go 1.22+ `http.ServeMux` với wildcard `/{room}` và `roomDispatcher` tương thích chuẩn mới.
  * Tự động điều hướng URL thông minh: truy cập `/` hoặc `/{room}` tự chuyển về `-s` (trên trình duyệt) hoặc `-r` (trên CLI / curl / PowerShell).
  * Nhúng toàn bộ thư mục `public/` tĩnh vào nhị phân qua `//go:embed public/*`.
  * Bổ sung Middleware Logging và CORS linh hoạt.

### Frontend Web SPA (`public/`)
* `public/index.html`:
  * Tách biệt rõ ràng 2 khung nhìn: `senderView` (Bên Phát) và `receiverView` (Bên Nhận).
  * Thẻ hiển thị vai trò trực quan ("Đầu Phát - Master" vs "Đầu Nhận - Worker").
  * Khu vực cheat-sheet lệnh mẫu 1-click copy dành riêng cho PowerShell và Linux curl.
* `public/style.css`:
  * Giao diện Developer Dark Mode hiện đại, trực quan, tối giản.
  * Hiệu ứng chỉ báo trạng thái sợi dây (đang chờ, đã nối, đang truyền dữ liệu).
* `public/app.js`:
  * Tự động nhận diện vai trò dựa trên hậu tố URL (`-s` hoặc `-r`).
  * Cơ chế Auto-Save script (debounce 300ms) mượt mà cho bên phát.
  * Hỗ trợ Drag & Drop file gửi đi với thanh tiến trình.
  * Đồng bộ trạng thái tức thì qua Server-Sent Events (SSE).

## 3. Kết Quả Kiểm Thử (Verification)
1. **Biên dịch nhị phân:**
   * Lệnh: `go build -ldflags="-s -w" -o textconnect.exe .`
   * Kết quả: Thành công, dung lượng file `textconnect.exe` đạt **7,086,080 bytes (~6.75 MB)**.
2. **Kiểm tra PowerShell slot rỗng:**
   * Lệnh: `irm http://localhost:18080/1-r | iex`
   * Kết quả: Server trả về `# TextConnect: (empty)\n`, PowerShell thực thi êm xuôi mã thoát 0, không còn lỗi `EmptyStringNotAllowed`.
3. **Kiểm tra truyền Script:**
   * Bên phát đẩy script qua `POST /1-s`.
   * Bên nhận `irm http://localhost:18080/1-r | iex` nhận và chạy ra output chuẩn màu xanh.
4. **Kiểm tra Burn-After-Read:**
   * Sau khi bên nhận tải xong, slot tự động kích hoạt burn và trở về trạng thái rỗng an toàn.
5. **Kiểm tra truyền File đơn lẻ:**
   * Bên phát upload file kèm header `X-Filename`.
   * Bên nhận `GET /1-r` nhận file với đầy đủ header `Content-Disposition`, tải về chính xác 100% nội dung binary/text.
6. **Kiểm tra giao diện Web:**
   * `http://localhost:18080/1-s`: Hiển thị khung soạn thảo và dropzone.
   * `http://localhost:18080/1-r`: Hiển thị khung Read-Only theo dõi tiến trình và nút sao chép lệnh.
