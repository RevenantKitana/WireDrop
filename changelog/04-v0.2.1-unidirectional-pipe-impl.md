# WireDrop v0.2.1 - Hiện Thực Hóa Sợi Dây 2 Đầu Thuần 1 Chiều
**Ngày phát hành:** 2026-11-16

### Added
- `room.go`: Struct `PipeSlot` quản lý dữ liệu nguyên tử (Text hoặc File) và `RoomState` khóa 2 đầu.
- `handler_pipe.go`: Hợp nhất xử lý luồng `-s` (phát) và `-r` (nhận), phản hồi an toàn `# TextConnect: (empty)\n`, từ chối kết nối thứ ba với HTTP 409.
- `public/`: Tách biệt 2 màn hình `senderView` (soạn thảo) và `receiverView` (thuần đọc), kèm cheatsheet 1-click cho Linux curl và Windows PowerShell.

### Changed
- `main.go`: Chuyển sang router Go 1.22+ wildcard `/{room}`, tự động điều hướng browser sang `-s` và CLI sang `-r`.
