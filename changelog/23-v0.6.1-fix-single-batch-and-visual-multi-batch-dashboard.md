# WireDrop v0.6.1 - Sửa Lỗi 0-Byte Single-Batch & Dashboard Đa Mảnh TX/RX
**Ngày phát hành:** 2026-11-18

### Fixed
- Sửa triệt để lỗi file 0-byte bằng cách chỉ giải phóng slot (`ClearSlot`) sau khi toàn bộ dữ liệu đã được stream hoàn tất xuống socket của client.

### Added
- Dashboard lưới đa mảnh trực quan (`.batch-grid`, `.batch-chip`) hiển thị trạng thái từng block trên cả TX và RX.
- Bảng đồng hồ tiến trình tải về (`recvFileProgressCard`) cho bên nhận RX.

### Changed
- Hợp nhất pipeline tải file phía client: Mọi file đều đi qua hàm chuẩn hóa `uploadChunkedFile(file)`.
- Nâng phiên bản `const Version = "v0.6.1"` trong `main.go`.
