# WireDrop v0.3.4 - Tối Giản Ngôn Ngữ & Trải Nghiệm Giao Diện (TX / RX)
**Ngày phát hành:** 2026-11-16

### Changed
- Chuẩn hóa thuật ngữ viễn thông: Thay thế "bên phát/bên nhận" bằng ký hiệu `TX` (`*-s`) và `RX` (`*-r`).
- Trực quan hóa sợi dây 1-1 bằng đèn LED tối giản: `TX ● ─── RX ○` và `TX ● ─── RX ●`.
- `public/`: Rút gọn tab chế độ thành `Text` và `File`, tối giản thông báo Toast và tiêu đề tab trình duyệt.

### Removed
- Xóa bỏ hoàn toàn banner diễn giải `.receiver-banner` trên giao diện bên nhận.
