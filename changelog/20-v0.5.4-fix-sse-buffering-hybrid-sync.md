# WireDrop v0.5.4 - Fix Cloudflare Quick Tunnel SSE Buffering & Hybrid Snapshot Sync
**Ngày phát hành:** 2026-11-17

### Fixed
- `handler_pipe.go`: Khắc phục nghẽn đệm Cloudflare Edge bằng cách trả về snapshot đầy đủ của phòng trong `GET /events?check=1`, chuẩn hóa header `Content-Encoding: identity` và tăng padding lên 4096 bytes.
- `public/app.js`: Áp dụng cơ chế Hybrid Sync — kết hợp HTTP Snapshot tức thì với SSE Realtime và fallback polling chu kỳ 3 giây khi SSE bị proxy/CDN chặn.
- `host.go`: Tự động ping warmup Cloudflare Edge trước khi hiển thị URL ra console.

### Added
- `sync_test.go`: Bổ sung bài test `TestCheckReturnsRoomSnapshot`.
